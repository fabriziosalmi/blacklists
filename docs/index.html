What you are installing

This is one list, not a menu. Alongside advertising, tracking, malware and phishing it also blocks gambling, piracy and streaming domains, because some upstream lists cover them. Domains counts what a category supplied; only from here counts what would be lost if it were dropped. Categories overlap heavily, so the first column does not sum to the list total.

Blocked without any source declaring it

The table above counts domains by how each upstream list labels itself. That cannot see a category no source declares - so these are classified by content instead, against the Universite Toulouse 1 Capitole reference lists, downloaded at build time and never redistributed.

What this list blocks among popular domains

A blocklist is easy to judge by size and hard to judge by correctness. Every release is cross-checked against the Tranco top-1M ranking. Many popular domains are blocked entirely on purpose - that is what an ad and tracker list is for - so this is published rather than hidden, with the source responsible for each one.

A separate list of protected domains - DNS resolvers, OS update and certificate endpoints, CDN apexes - is checked on every release and fails the build rather than shipping. Blocking something here by mistake? Report it.

Licences are recorded only when confirmed against the upstream repository, licence page or list header; anything else is marked unverified rather than guessed. If you maintain one of these lists and the attribution is wrong, open an issue and it will be corrected.
